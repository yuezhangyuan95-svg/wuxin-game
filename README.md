# 武新电气 · 经营模拟（wuxin-game）

基于「武新电气经营驾驶舱」demo 改造的**模拟经营培训游戏**：你接任一家中型电气设备制造企业的总经理，在 30 个游戏日内通过报价接单、生产交付、现金流管理把公司经营好，第 30 天结算 KPI 评分（S/A/B/C）并生成经营复盘报告。

## 快速开始

- **无需安装、无需构建**：浏览器直接打开 `index.html` 即可玩（纯 HTML/CSS/JS，无依赖）。
- 开始界面三档难度仅初始资金不同：新手 8,000 万 / 标准 6,000 万 / 专家 4,500 万。
- 一局约 6.5 分钟（固定 2x，游戏内 1 天 = 12.5 现实秒）。

## 玩法要点

- **每日 1 商机**：到达时驾驶舱居中弹窗并暂停时间；成本只给区间估算、报价仅有一次机会——在中标率与毛利之间押注。
- **合同条款谈判**：宽松/均衡/苛刻三组合，客户接受率 95%/82%/60%，拒签即丢单。
- **订单管线**：中标 → 排产 → 生产 → 质检 → 交付 → 回款；逾期按日扣违约金，准期率是命脉。
- **四类决策实时涌入收件箱**：商务合同 / 生产运营 / 人事 / 突发事件（坏账、环保、工伤、税务等支出型事件）。
- **第 30 天复盘**：KPI 六维加权评分 + 现金曲线 / 雷达图 / 报价散点图 / 决策时间线 / 失误→知识点点评，可继续沙盒经营。

## 项目结构

```
index.html          页面骨架(驾驶舱布局, 双击可玩)
css/main.css        样式(继承驾驶舱 demo 蓝白视觉)
js/data.js          内容数据: 开局状态/商机产品池/决策模板/经营手册
js/state.js         游戏状态 + localStorage 存档(版本校验)
js/pricing.js       报价与中标概率模型(成本区间估算/AI 模糊预估)
js/engine.js        时间引擎: 日结经济/订单管线/商机开标/随机事件
js/review.js        结算评分 + 复盘报告(SVG 图表, 配色已过色觉校验)
js/agent.js         游戏内 Agent 助手(自建 API + 离线规则降级)
js/ui.js            全部视图渲染与交互
docs/DESIGN.md      设计文档(唯一权威设计来源)
tools/smoke-test.js 引擎冒烟测试(node tools/smoke-test.js)
```

## Agent 问答 API 约定（部署时）

- 地址：`POST /api/chat`（与游戏同域部署，服务端代理转发大模型，可挂 RAG 知识库；密钥只放服务端）
- 请求：`{"message": "用户问题", "context": {"day", "date", "cash", "receivable", "orders", "decisions", "risks"}}`
- 响应：`{"reply": "回答文本"}`
- API 不可达时前端自动降级为内置规则问答，本地 file:// 打开也可玩。
