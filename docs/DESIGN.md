# 武新电气 · 经营模拟 — 游戏设计文档（v1）

> 基于「武新电气经营驾驶舱」demo（http://118.89.152.20:8100）改造的模拟经营培训游戏。

## 0. 一句话概念

玩家扮演武新电气新任总经理，接手一家经营中的电气设备制造企业，在 **90 天（一个季度）** 内通过报价接单、生产交付、回款管理，把公司经营好。界面就是企业驾驶舱本身，时间实时流逝（1x = 25 秒/游戏日），商机与决策实时涌入收件箱，**关键决策到达时自动暂停**。季度末按 KPI 加权评分（S/A/B/C）并生成经营复盘报告。

## 1. 核心决策记录（已与用户确认）

| 项目 | 决定 |
|---|---|
| 节奏 | 固定 2x 实时流逝；商机弹窗出现时自动暂停，决策(提交报价/稍后处理)后恢复（v1.2） |
| 技术形态 | 原生 HTML/CSS/JS 多文件，无构建，浏览器直接打开 |
| 周期 | 30 天（一个经营月），结算后可继续沙盒 |
| 流速 | 固定 2x（游戏 1 天 = 12.5 现实秒） |
| 订单玩法 | 纯报价式：所有商机玩家亲自报价，AI 顾问给中标概率反馈，报价仅可提交一次 |
| 评分 | KPI 加权评分（S/A/B/C）+ 复盘报告 |
| 数值量级 | 千万级（现金数千万，单笔订单百万~千万） |
| 决策类型 | 四类全做：商务合同 / 生产运营 / 人事 / 突发事件 |
| 难度 | 三档仅初始资金不同（新手 8,000 / 标准 6,000 / 专家 4,500 万），其余条件一致 |
| 中标难度 | 全局中标率下修 18%，对手竞争强度 0.85~1.45（波动大）；突发事件 35%/天 |
| 报价信息 | 成本仅显示区间估算（±8%，精确值未知），AI 预估中标率模糊（±9%），报价需自行判断（v1.3） |
| 支出事件 | 坏账 / 设备老化维修 / 环保检查 / 暴雨受损 / 税务稽查 / 工伤 / 物流索赔（申诉类有 50% 概率加倍罚款） |
| 开局 | 接手中型企业（继承 demo 世界观与在手订单） |
| Agent 接口 | 自建问答 API（POST /api/chat），前端规则制降级，密钥只在服务端 |
| 开发分工 | 游戏前端全部由本会话开发；服务器开发会话负责 Agent 服务与部署调试 |
| 商机频率 | 每日固定 1 条（到达时驾驶舱首页弹窗，点击跳转收件箱报价） |
| 开局决策 | 5 项决策中投标/报价 2 项转报价式商机，合同评审/ECN/放行 3 项保持审批式 |
| 交付顺序 | 交互优先：M1 骨架 → 决策框架+报价+经济模拟合并交付 → 四类决策扩充 → 评分复盘 → 难度平衡 |

## 2. 游戏循环

```
市场生成商机 ──> 玩家报价（AI反馈中标率）──> 截止开标
    中标 ──> 签订合同（条款谈判）──> 排产 ──> 物料采购 ──> 生产 ──> 出厂试验/放行 ──> 交付 ──> 回款
    未中标 ──> 收到复盘线索（如"对手低3%"）
期间：突发事件、人事、ECN 等决策涌入收件箱；每日 18:00 生成日报
第 90 天 18:00 ──> 季度结算：KPI 评分 + 复盘报告 ──> 可选继续沙盒经营
破产（现金断流无法周转）──> 提前结束，评 F
```

## 3. 时间系统

- 游戏内 1 天 = 25 秒（1x），**固定 2x 运行（1 天 = 12.5 现实秒）**（v1.1 优化：训练节奏更快，决策必须在时间流动中处理，逾期压力真实）。
- **商机弹窗机制**（v1.2）：新商机到达 → 驾驶舱居中弹出大弹窗（产品/金额/AI 建议/截止日）→ 时间自动暂停；提交报价或点「稍后处理」→ 恢复 2x 流动。取消报价弹窗则回到商机弹窗、时间保持暂停。
- 一天按时刻推进（09:00 上班 → 18:00 下班），事件带时刻戳（展示用）。
- 其他决策/突发事件到达时以轻提示 + 收件箱角标提醒，不打断时间流动。
- 每日 18:00 自动生成日报，学员可随时查阅。
- 顶栏时间条显示游戏内时刻/日期/星期/天气与周期进度（继承 demo 视觉）。

## 4. 经济系统（千万级）

### 初始状态（标准档，接手时局面）

| 项目 | 数值 | 备注（沿用 demo 素材） |
|---|---|---|
| 现金 | 6,000 万 | |
| 应收 | 630 万（2 笔在账） | 火电厂 480 万（账龄 35 天）、质保金 150 万；WX-2026-007 放行交付后另有 1,400 万到货款挂账 |
| 固定资产 | 8,000 万 | 月折旧约 100 万 |
| 在手订单 | 4 单 / 7,200 万 | 津巴布韦变压器、广州 PCS、潜油泵 110 套、升压变压器 8 台 |
| 月固定支出 | 约 400 万 | 工资 300 万 + 管理/水电物业 100 万 |
| 产能 | 月产值约 4,000 万 | 工厂A（成套）70%、工厂B（电子装配）30% |
| 员工 | 120 人 | 生产 80 / 技术 20 / 职能 20 |
| 客户关系 | 80 / 100 | 条款拒签/投诉/拒绝赔偿会扣减, 影响季度 KPI(10%) |

### 收入与成本

- **收入**：订单交付后按合同回款——预付款 10~30%（签约到账）、到货款 60~80%（交付后按账期 30/60/90 天）、质保金 5~10%（180 天后）。账期越长回款越慢，现金流压力越大（培训点）。
- **成本**：物料成本（成本率约 70~80%，受材料价格波动影响）、生产制造成本、加急采购溢价（+20%，周期 15 天→3 天）、逾期违约金（合同条款 0.05/0.1/0.2% 每日——逾期 10 天即吞掉 5~20% 合同额，准期率是命脉）。
- **融资**：银行短期贷款（限额 = 净资产 × 30%，月息 1.2%，到期可续借决定）——培训安全阀。

### 商机生成（市场引擎）

- 每天按难度生成 0~2 单商机：产品类型（变压器/PCS/潜油泵/开关柜/箱变…）× 客户类型（油田/风电/光伏/电网/海外），含：数量、成本估算、交期要求、客户历史账期、投标截止（3~7 天）、竞争强度。
- 单笔金额 150 万 ~ 1,600 万（平衡调参后：两厂月产能 4,000 万，按每天 1 商机 × 约 40% 中标率反推，小单为主、大单偶发，使满产节奏下逾期压力可控而非必崩）。
- 难度三档：新手（资金 8,000 万 · 商机更多 · 对手弱 0.75~0.95 · 事件×0.6 · AI 建议清晰）/ 标准（6,000 万 · 0.9+0.1 · 0.85~1.15 · ×1.0）/ 专家（4,500 万 · 商机更少 · 对手强 0.95~1.35 · 事件×1.4 · 中标率 -8% · AI 预估区间更宽）。

## 5. 报价系统（核心玩法）

1. 商机到达 → 驾驶舱居中弹出商机大弹窗（时间自动暂停）→「去报价」打开报价弹窗（或「稍后处理」恢复时间）。
2. 玩家打开商机 → AI 顾问给出：成本估算、历史中标价区间、建议报价、**中标率随报价变化的预估**。
3. 玩家输入报价 → AI 实时反馈预估中标率 + 预计毛利 → 提交。**报价仅可提交一次，提交后不可修改**（v1.1 优化：决策更慎重）。
4. 截止时按中标概率掷骰开标。中标 → 进入合同/订单管线；未中标 → 收件箱收到结果（含复盘线索，如"对手报价低 3%"、"资质不符"——demo 素材里的真实弃单原因）。

**中标概率模型**：报价在历史中标区间内 → 中标率约 40~70%；低于区间 → 概率升高但毛利薄甚至亏钱；高于区间上限 → 概率快速衰减至 20% 以下。对手报价按难度档分布抽样。AI 预估为区间值（专家档区间更宽、建议更模糊）。

**培训点**：报价偏高丢单、偏低亏钱、平衡才是利润；demo 数据里"报价偏高、资质不符"导致的废标历史就是教材。

## 6. 决策类型池（四类）

每条决策带 AI 顾问建议 + 2~4 个选项，选项标注预期后果；选择后经模拟天数出结果，收件箱收到结果通知。

### A. 商务合同类
- **合同条款谈判**（每次中标后触发）：三组合三选一——宽松（预付10% · 账期90天 · 违约金0.2%，接受率95%）/ 均衡（预付30% · 账期45天 · 违约金0.05%，接受率82%）/ 苛刻（预付50% · 账期30天 · 违约金0.02%，接受率60%）。条款苛刻 → 现金流稳但客户可能拒签直接丢单（客户关系 -3）；AI 建议根据当前现金水位给出。

### B. 生产运营类
- **插单/排产**：新订单交期与在手订单冲突时，选择优先顺序（谁逾期谁受损）。
- **采购加急**：缺料时加急采购（贵 20%）vs 等待到货（可能延误交期）。
- **设计变更 ECN**：批准（成本 +1.2 万级、不影响交期）vs 驳回（客户关系受损）。
- **出厂放行**：出厂试验有问题或逾期时，放行（准期但质量风险）vs 返工（延误但稳妥）。

### C. 人事类
- **工程师外派**：接外派订单（收入 + 客户关系）vs 拒绝（保住内部产能）。
- **招聘**：花钱 + 4 周周期换产能提升（+10%/批）。
- **培训**：花钱 + 1 周，准期率临时提升。

### D. 突发事件类
- 设备故障（维修停产几天 vs 外包生产）、客户投诉（赔偿 vs 关系）、材料涨价/缺货、政策变化（补贴利好/监管趋严）、员工离职等。

## 7. 生产与交付

- 订单按交期排产，两工厂产能占用可视（沿用 demo「产能状况」卡片，加产能利用率进度条）。
- 每单 2 种关键物料（如铜排/变压器油、PCB/元器件），采购周期 5~15 天，缺料停工延误交期。
- 出厂试验环节，小概率发现质量问题 → 触发放行决策。
- **准期率** = 按期交付 / 总交付，是评分大项，也是违约金风险来源。

## 9. KPI 评分与复盘

季度末加权评分：

| 维度 | 权重 |
|---|---|
| 净利润 | 30% |
| 现金流健康（期末现金 + 未断流天数） | 20% |
| 交付准期率 | 20% |
| 中标率与报价质量（平衡：太高可能利润薄） | 15% |
| 客户关系 | 10% |
| 风险处置（突发事件处理质量） | 5% |

- 评级：S ≥ 90，A ≥ 75，B ≥ 60，C < 60；破产 = F。
- 已实现的评分口径（30 天口径满分线）：净利润 1,200 万 / 期末现金 7,000 万 / 准期率 100% / 中标率 40% + 中标单平均毛利率 25% / 客户关系 100 / 风险处置全部采纳 AI 建议。报告含现金曲线、六维雷达、报价散点（中标/未中标/放弃三色已过色觉校验）、决策时间线、失误→知识点点评、标杆对比与重玩建议。
- **复盘报告**：现金曲线、KPI 雷达图、报价散点图（报价 vs 结果标注）、关键决策时间线（每条决策 + 实际后果）、知识点点评（每个失误对应一条经营讲义）、与"标杆经营"对比、重玩建议。

## 10. 技术架构

```
wuxin-game/
  index.html          — 页面骨架（继承 demo 布局）
  css/main.css        — 样式（继承 demo 蓝白视觉）
  js/data.js          — 内容数据：商机模板、事件池、决策模板、产品物料库、讲义知识点
  js/state.js         — 游戏状态 + localStorage 自动存档（单槽位，随时续玩）
  js/engine.js        — 时间循环、经济模拟、事件生成、KPI 计算
  js/pricing.js       — 报价/中标概率模型
  js/ui.js            — 渲染与交互（收件箱、驾驶舱、时间条、弹窗）
  js/agent.js         — 游戏内 Agent 助手（调自建问答 API，不可达时降级规则制）
  js/review.js        — 结算与复盘报告（含图表）
  docs/DESIGN.md      — 本文档
```

- 纯 `<script>` 标签引入（不用 ES modules，双击 index.html 即可玩）。
- **Agent 助手 v1 为规则制**（问答游戏状态：现金、商机、风险）；v2 可接真实 LLM + 你们 RAG 项目里的电气知识库联动。
- 图表（复盘雷达图/曲线/散点）：用轻量原生 SVG 自绘，不引第三方库。

### Agent 问答 API 约定（与服务器会话对接）

- 地址：`POST /api/chat`（与游戏同域部署，服务端代理转发大模型，可挂 RAG 知识库）
- 请求：`{"message": "用户问题", "context": {"day", "date", "cash", "receivable", "orders", "decisions", "risks"}}`
- 响应：`{"reply": "回答文本"}`
- 前端在 API 不可达时自动降级为内置规则问答
